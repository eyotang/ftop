# ftop 0.1.0 validation preview

GPUI rendering with GPUI Kit Base components and custom floating-panel styling. Includes separate Linux, macOS and Windows collectors. macOS hardware collection reuses the attributed upstream C bridge. Updates currently open manual release downloads.

## Packages

- Ubuntu 24.04 x86_64: `.deb`.
- Windows x86_64: unsigned portable ZIP.
- macOS: `.app` ZIP for the architecture shown in the filename; not a universal build, not notarized.

All three platform jobs must pass formatting, compilation, tests and release packaging before assets are attached. These checks do not establish native installation or hardware acceptance. macOS and Windows native launch, sensors, appearance, and installer behavior remain unverified. Ubuntu native launch was checked on 26.04; installation on the 24.04 baseline remains unverified.

## Known limitations

This is a validation preview, not a stable release or a declaration of full upstream parity. The measured visible Ubuntu release build used about 2.13% of one CPU core and 116 MiB RSS, exceeding the original benchmark target. Cross-platform performance and latest minimized-window behavior need further native validation. X11 input methods may require `XMODIFIERS=@im=none` on affected hosts.

## macOS first launch

Verify `SHA256SUMS` and trust the download before installing `ftop.app` in `/Applications`. This build is not notarized. If macOS blocks this trusted application because of its download quarantine attribute, remove only that application's quarantine marker:

```bash
xattr -dr com.apple.quarantine /Applications/ftop.app
```

Use `sudo` only if permissions require it. This removes the download quarantine marker for this application; it does not sign or notarize it.

No stable update manifest is published for this preview. Existing installations will not be directed to it through the stable update checker.
