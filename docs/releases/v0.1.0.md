# ftop 0.1.0

GPUI rendering with GPUI Kit Base components and custom floating-panel styling. Includes separate Linux, macOS and Windows collectors. macOS hardware collection reuses the attributed upstream C bridge. Updates currently open manual release downloads.

## Changes

- Add the original owl application icon to macOS bundles and Windows executables.
- Associate Ubuntu desktop launchers with the application icon.
- Show GPU usage percentages above the GPU bar and in the GPU reading.
- Add CPU, memory, GPU, network, power and temperature icon tooltips.
- Add a macOS DMG with an Applications drag-and-drop install target.
- Build Windows as a GUI application so launch does not open a CMD window.
- Connect Windows WDDM GPU engine and memory counters, driver-reported CPU frequency/max, native performance/efficiency classes and ACPI thermal zones.
- Connect Linux AMD sysfs and Intel PMU/DRM GPU counters; add optional NVIDIA NVML on Windows/Linux for supported utilization, memory, clocks, temperature and power.
- Add Linux RAPL CPU package power, battery discharge power, Zswap/Zram compression and memory PSI; add Windows battery discharge telemetry.
- Explain hardware/permission limitations in icon tooltips and collection status instead of silently empty readings.

## Packages

- Ubuntu 24.04 x86_64: `.deb`.
- Windows x86_64: unsigned portable ZIP.
- macOS Apple Silicon (arm64): DMG (recommended) and `.app` ZIP; not a universal build, not notarized.

All three platform jobs must pass formatting, compilation, tests and release packaging before assets are attached. These checks do not establish native installation or hardware acceptance. macOS and Windows native launch, sensors, appearance, and installer behavior remain unverified. Ubuntu native launch was checked on 26.04; installation on the 24.04 baseline remains unverified.

## Known limitations

This release does not establish full upstream parity. Earlier visible Ubuntu release runs used about 2.13–3.67% of one core and 116 MiB RSS. A GPU-enabled 20-second run used 2.9% of one core and 121 MiB RSS, still exceeding the original benchmark target. Cross-platform performance needs further native validation. A local X11 minimized-window run measured 0.47% of one core; this does not establish visible-window acceptance. X11 input methods may require `XMODIFIERS=@im=none` on affected hosts.

## macOS first launch

Verify `SHA256SUMS`, open the DMG, then drag `ftop.app` onto the Applications folder. Eject the disk image and launch ftop from Applications. This build is not notarized. If macOS blocks this trusted application because of its download quarantine attribute, remove only that application's quarantine marker:

```bash
xattr -dr com.apple.quarantine /Applications/ftop.app
```

Use `sudo` only if permissions require it. This removes the download quarantine marker for this application; it does not sign or notarize it.

Includes a manual-download update manifest; updates open the Release page and do not replace the application automatically.
