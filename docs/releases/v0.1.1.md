# ftop 0.1.1

本次更新补齐多语言，并修正 GPU 标题、悬停说明及主题细节。使用 GPUI 渲染和 GPUI Kit Base 组件，保留 macOS、Windows、Ubuntu 各自的原生采集器。

## 更新内容

- 新增简体中文、英语、日语、韩语；默认跟随系统，不支持的系统语言回退为英语。
- 在 **••• → 语言 / Language** 中切换，即时生效并保存。旧配置自动保留原有选项。
- 翻译设置、指标悬停说明、采集状态、可用性提示和更新状态；保留进程名称、硬件/API 标识和计量单位。
- 将 CPU/GPU 标题放入同一行，统一强调字号、圆形徽标与占用圆环，保持柱状条上下对齐。
- 扩展指标悬停范围至图标和数值，GPU 柱也可查看详细采集说明，并加入轻微悬停高亮。
- GPU 使用明确的显卡图标；CPU、GPU 和内存配色跟随浅色/深色及海、石墨、暖色主题。
- 修正面板间距、核心数值字重及排序按钮说明；窄窗口为设置按钮预留空间。
- 沿用应用图标、macOS 拖入 Applications 安装，以及 Windows 无 CMD 窗口的 GUI 构建。

## 下载与升级

先退出旧版 ftop，再安装对应平台的新包。无需删除配置文件。

- **macOS 14+，Apple Silicon / arm64**：下载 `.dmg`，打开后将 `ftop.app` 拖到 **Applications**，选择替换，推出磁盘映像，再从应用程序启动。也提供 `.app` ZIP；不是 Universal/Intel 构建，未经公证。
- **Windows x86_64**：下载便携 ZIP，解压并替换旧目录中的可执行文件，运行 `ftop.exe`。未签名。
- **Ubuntu x86_64**：下载 `.deb`，在下载目录执行：

```bash
sudo apt install ./ftop-0.1.1-linux-x86_64.deb
```

Ubuntu 包以 24.04 为构建基线。本机原生显示与性能验证使用 Ubuntu 26.04；24.04 安装后的桌面验收尚未完成。

更新仍为手动下载：旧版 **••• → Check for updates / 检查更新** 检测到 0.1.1 后可打开本发布页，不会自动下载或覆盖正在运行的程序。较早的 preview.1 内部版本也是 0.1.0，可直接手动安装本版本。

## macOS 首次启动与 xattr

先核对 `SHA256SUMS`，确认来源可信并完成上述安装。若 macOS 因下载隔离属性阻止启动此未公证应用，可仅移除已安装 ftop 的隔离标记：

```bash
xattr -dr com.apple.quarantine /Applications/ftop.app
```

仅在权限不足时使用 `sudo`。该命令只移除此应用的下载隔离标记，不会为应用签名或公证。

## 验证与已知差异

三个平台的格式、编译、测试和打包检查均需成功后才发布。macOS 打包检查 DMG、应用图标和 Applications 链接；Windows 打包检查 GUI 子系统；这些检查不代表三端原生界面、安装和硬件读数全部验收。

本机 Ubuntu X11 已检查四种语言、浅色/深色及宽/窄布局。15 项测试覆盖语言匹配、回退、旧配置兼容等。最终 UI/多语言开发版 Release 的 20 秒测量为 **单核 CPU 2.80% / 12 线程整机 0.233% / RSS 118.54 MiB**，改动前为 **2.90% / 0.242% / 119.62 MiB**。短测未见明显新增开销，但仍未达到原版单核 1% 的目标；macOS/Windows 性能未实测。

应用专属进程图标、双进程榜、压缩内存分段和设置面板形态仍与原版不同。参见 [UI 对照](https://github.com/eyotang/ftop/blob/v0.1.1/docs/UI-COMPARISON.md)。macOS/Windows 原生界面、输入、字体及安装后的硬件验收，Ubuntu Wayland 输入验收仍待完成。硬件/驱动/权限无法提供的指标会显示不可用，不编造零值。
