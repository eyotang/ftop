# ftop 0.1.2

将设置和更新集中到独立页面，保持主监控窗口简洁。

## 更新内容

- 点击右上角“…”进入独立设置页，返回或 Esc 回到监控；不再展开主窗口设置或插入更新卡片。
- 更新区域支持检查状态、固定版本的分平台下载、发布说明与安装引导；Ubuntu 可复制安装命令。
- 发现新版时“…”高亮，进入设置自动展示安装引导。
- 右上角固定显示最小化和退出；支持 Cmd/Ctrl + M、Q、U 和逗号快捷键。
- 四语言文案同步更新，窄窗口下按钮与说明换行。
- 沿用原生平台采集器与刷新策略；没有新增轮询、常驻动画或采集任务。

## 下载与升级

先退出旧版 ftop，再安装对应平台的新包。无需删除配置文件。

- **macOS 14+，Apple Silicon / arm64**：下载 `.dmg`，打开后将 `ftop.app` 拖到 **Applications**，选择替换，推出磁盘映像，再从应用程序启动。也提供 `.app` ZIP；不是 Universal/Intel 构建，未经公证。
- **Windows x86_64**：下载便携 ZIP，解压并替换旧目录中的可执行文件，运行 `ftop.exe`。未签名。
- **Ubuntu x86_64**：下载 `.deb`，在下载目录执行：

```bash
sudo apt install ./ftop-0.1.2-linux-x86_64.deb
```

Ubuntu 包以 24.04 为构建基线。本机原生显示与性能验证使用 Ubuntu 26.04；24.04 安装后的桌面验收尚未完成。

应用会自动检查更新；进入 **… → 设置 → 更新** 可手动检查、下载对应平台安装包并查看安装指引。发现新版时“…”高亮提示。当前仍需手动安装，不会自动覆盖或重启应用。旧版本也可通过原有检查更新入口访问本发布页。

## macOS 首次启动与 xattr

先核对 `SHA256SUMS`，确认来源可信并完成上述安装。若 macOS 因下载隔离属性阻止启动此未公证应用，可仅移除已安装 ftop 的隔离标记：

```bash
xattr -dr com.apple.quarantine /Applications/ftop.app
```

仅在权限不足时使用 `sudo`。该命令只移除此应用的下载隔离标记，不会为应用签名或公证。

## 验证与限制

三平台格式、编译、17 项测试和打包须成功后发布；macOS 验证 DMG、图标与 Applications 链接，Windows 验证 GUI 子系统。Ubuntu X11 已验证主界面和设置页宽窄布局，临时 GPUI 鼠标事件验证“…”进入设置，测试注入已移除。CI 不代替 macOS/Windows 原生界面、硬件或安装验收，Ubuntu Wayland 输入仍待验收。

本版未重新测量性能；此前版本本机单核 CPU 约 2.85–3.10%，仍未达到单核 1% 目标，macOS/Windows 性能未实测。当前更新为自动检测、手动安装，不提供签名自动安装通道。硬件或权限无法提供的指标明确显示不可用。
